# 108번뇌 꿰기

바늘 하나로 염주 108알을 꿰는 정적 웹 게임. Getting Over It 식으로, 결국 할 수는 있지만 억울하게 어렵도록 설계했다.

## 난이도 설계 의도

- 실은 위 고리에 묶여 있고 꿴 알은 중력으로 실 위를 미끄러진다. 알 더미의 수위가 바늘귀보다 높아지면(바늘을 깊이 내리면) 줄줄이 빠진다. 체크포인트는 없다.
- 알이 늘수록 실이 길어지고 알이 더 깊은 곳에 나타난다. 대략 화면 60% 깊이까지는 안전하고, 그보다 깊은 알은 빠르게 찍고 올라와야 한다.
- 구멍 허용 오차 감소, 알 회전, 흔들림, 손떨림이 진행도에 비례해 커진다.
- 쉬움·보통·어려움은 같은 곡선을 쓰되 출발 난이도만 다르다. 어려울수록 처음부터 곡선의 중턱에서 시작하고, 끝은 모두 같은 최고 난이도로 모인다. 순위표는 두지 않는다 — 비교도 번뇌라서.
- 방해 요소는 모두 예고가 있다. 산바람은 나뭇잎이 먼저 날리고, 고양이 발은 화면 끝에서 천천히 들어오며, 번뇌 알은 붉게 맥동하고, 한쪽 방향 알은 화살표로 표시된다. 각 요소가 처음 나올 때 한 번 설명 멘트를 띄운다. 억울하되 속였다는 느낌은 들지 않게 하려는 것이다.
- 한쪽 방향 알과 번뇌 알은 회전하는 알(10알 이후)에만 붙는다. 회전하다 보면 반드시 수평이 되는 순간이 오므로 어느 방향으로든 꿸 수 있는 자세가 생긴다. 번뇌 알은 진짜 알 옆에 따로 나타나 피해 갈 수 있다.

## 로컬 실행

```sh
python3 -m http.server 8000
```

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 push 한다.
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/ (root)`.
3. `index.html` 의 `og:image` 는 SNS 미리보기를 위해 절대 URL(`https://<user>.github.io/<repo>/og.png`)로 바꾸는 것이 좋다.
